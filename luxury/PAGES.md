## Before building

- **Material and collection pages** (Bouclé, Leather, Stoneware and similar) could be filters on the main category page instead of separate pages. That would cut about 30 pages.
- **On Shopify** every collection above is one collection set up in the admin, all using the same collection template. Building the template once covers them all.

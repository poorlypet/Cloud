Shot list

Every photo and film the site is waiting for, grouped by export size so you can shoot and export each batch in one go. Copy a name, save the file with exactly that name, and upload it to Shopify. It appears on the site on its own.

1. Name it exactly

Lower case, hyphens, and the same ending (.jpg or .mp4). Shopify adds _1 to a name it has already seen, so delete an old version before uploading its replacement.

2. Upload to Files

Shopify admin › Content › Files › Upload files. Several at once is fine.

3. Ask for a refresh

Tell Claude to update the shot list. It checks Shopify and marks what has arrived. Your own ticks stay in this browser.

Product photography

Product photos are added on each product in Shopify (Products › the product › Media), so they don’t need special names. Shoot them square, 2048 × 2048, on a plain light ground with the piece centred and a little space around it. The first photo is the one on product cards. Brand banners can also be set on each brand’s collection (Products › Collections › Image), which takes priority over the named file.

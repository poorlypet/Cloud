## Design system (from css/home.css)

- Teal `#0F4C48`, deep teal `#0A3A37`, lime `#DFE43A` (hover `#D2D82C`), coral `#F0614A`
- Ink `#0E2A28`, mute `#5B6B69`, mist `#F2F4F3`, lines `#E3E8E6` / `#C6D0CE`, pale green `#E4EED6`
- Type: Figtree (body), Domine serif (headings and highlighted `<em>` words)
- Radii 8 / 16 / 24px, gutter 24px (16px on mobile), max width 1440px
- Buttons: lime with teal text by default, `.sec` is teal with white text
